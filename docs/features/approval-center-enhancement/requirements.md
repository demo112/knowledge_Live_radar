# Requirements: 审批中心增强 (Approval Center Enhancement)

## Overview

对现有的审批中心进行功能增强和体验优化。主要包含三个方面：支持批量审批操作以提高效率；修复黑暗模式下的 UI 显示问题；提供清理所有待审批项的能力以解决数据积压问题。

## User Stories

### Story 1: 批量审批提案

As a 审批管理员, I want 能够批量选择和处理审批提案, so that 我可以快速处理大量积压的审批，提高工作效率

**Acceptance Criteria:**

- [ ] AC1: 列表项多选功能
  - **Given**: 审批列表中有多条待审批项
  - **When**: 用户点击列表项前的复选框
  - **Then**: 该项被选中/取消选中，界面显示当前已选中的数量

- [ ] AC2: 批量通过
  - **Given**: 用户选中了至少 1 条待审批项
  - **When**: 用户点击「批量通过」按钮并确认
  - **Then**: 
    - 系统对选中项逐一执行「通过」操作
    - 执行成功的项从列表中移除（或状态更新）
    - 执行失败的项保留并提示错误原因
    - 操作完成后显示总结报告（成功 X 条，失败 Y 条）

- [ ] AC3: 批量拒绝
  - **Given**: 用户选中了至少 1 条待审批项
  - **When**: 用户点击「批量拒绝」按钮并确认
  - **Then**: 
    - 系统对选中项逐一执行「拒绝并删除」操作
    - 所有选中项从数据库中物理删除
    - 列表自动刷新

### Story 2: 清理所有待审批项

As a 审批管理员, I want 能够一键清理所有待审批项, so that 我可以快速解决历史积压的数据问题

**Acceptance Criteria:**

- [ ] AC1: 一键清理（全部删除）
  - **Given**: 系统中存在状态为 Pending 的审批提案（可能跨多页）
  - **When**: 用户点击「清理所有待审批项」按钮并经过二次确认
  - **Then**: 
    - 系统将所有 Pending 状态的提案物理删除
    - 列表被清空，显示「暂无待审批项」
    - 返回清理的数量提示

### Story 3: 黑暗模式 UI 修复

As a 用户, I want 按钮在黑暗模式下清晰可见, so that 我可以正常进行操作而不受视觉干扰

**Acceptance Criteria:**

- [ ] AC1: 按钮文字适配黑暗模式
  - **Given**: 系统处于黑暗模式（Dark Mode）
  - **When**: 用户查看审批列表中的操作按钮（通过/拒绝/影响分析）
  - **Then**: 
    - 按钮背景色与文字颜色对比度符合无障碍标准（>4.5:1）
    - 不会出现「白底白字」或「黑底黑字」的情况
    - 拒绝按钮在黑暗模式下应有清晰的边框或背景区分

## Constraints

- **性能要求**: 批量操作（如 50 条）响应时间应 < 5 秒；全量清理操作应在后台异步执行或有进度提示（如果数据量极大）。
- **安全要求**: 只有具备审批权限的用户才能执行批量操作。

## Out of Scope

- 批量撤销（Rollback）：目前仅支持批量通过/拒绝。
- 复杂的筛选批量：目前仅支持当前列表勾选或全量清理。

## Assumptions

以下假设已与用户确认：
- [x] "清理"的操作定义为"批量拒绝"，保留历史记录但不再处于待审批状态。
- [x] 批量操作不需要逐个填写拒绝理由，统一使用默认理由或用户输入一个理由应用到所有项。
- [x] 黑暗模式下的按钮样式主要修复颜色对比度问题。
