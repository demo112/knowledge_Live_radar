# 需求文档：抖音视频转文档组件

## 概览 (Overview)

这是一个独立的组件功能，旨在将抖音短视频内容转化为可阅读的结构化文档。用户只需输入一个抖音分享链接，系统将自动下载视频、提取音频并转录为文字，最后利用大语言模型（LLM）对内容进行整理，生成包含标题、摘要、关键点和全文的 Markdown 文档。这使用户能够快速归档和阅读视频内容。

## 用户故事 (User Stories)

### Story 1: 将抖音视频转换为文档

作为一个用户，我想要输入一个抖音视频链接，以便获得一份总结视频内容的文本文档。

**验收标准 (Acceptance Criteria):**

- [ ] AC1: 成功处理有效的抖音链接
  - **Given**: 后端服务正常运行且网络可访问
  - **When**: 我向 `/api/v1/tools/douyin-to-doc` 发送一个包含有效抖音分享链接（如 `https://v.douyin.com/kcvMfv/`）的 POST 请求
  - **Then**:
    - 系统成功下载视频或音频流
    - 系统将音频转录为文本
    - 系统生成一份结构化的 Markdown 文档
    - API 返回 200 OK 和生成的文档内容

- [ ] AC2: 处理无效链接
  - **Given**: 后端服务正常运行
  - **When**: 我发送一个无效的 URL 或非抖音平台的链接
  - **Then**: API 返回 400 Bad Request，并附带错误信息 "无效的抖音链接"

- [ ] AC3: 内容组织结构
  - **Given**: 一个包含语音内容的视频
  - **When**: 文档生成完成
  - **Then**: 文档应包含以下部分：
    - **标题**：由 LLM 根据内容生成或提取
    - **摘要**：视频内容的简短总结
    - **关键点**：以列表形式列出的核心信息
    - **全文转录**：完整的语音转文字内容（可选或附在最后）

## 约束条件 (Constraints)

- **性能**：整个处理流程应在合理时间内完成（例如，1分钟的视频处理时间不超过1分钟）。
- **依赖**：必须使用开源工具进行下载（如 `yt-dlp` 或 `douyin-tiktok-scraper`）和 ASR（如 `faster-whisper` 或 SiliconFlow ASR）。
- **独立性**：该组件应尽可能模块化，作为一个独立的服务或后端的一个清晰模块，不深度耦合现有业务逻辑。

## 范围外 (Out of Scope)

- **批量处理**：暂不支持一次性输入多个链接。
- **复杂 UI**：初期仅提供最基础的输入框和结果展示，不涉及复杂的交互设计。
- **视频存储**：视频文件仅用于临时处理，处理完成后即删除，不进行持久化存储。

## 假设 (Assumptions)

- 我们可以复用现有的 SiliconFlow API Key 进行 LLM 摘要和（如果可用）ASR 服务。
- 运行环境允许安装必要的系统依赖（如 `ffmpeg`）用于音频处理。

## 元数据 (Metadata)

- **规模**：小
- **涉及模块**：`tools/douyin`
- **技术栈**：Python, FastAPI, yt-dlp, OpenAI/SiliconFlow
- **状态**：草稿
