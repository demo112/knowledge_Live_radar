# Requirements: 内容清洗与批量摘要增强

## Overview

本项目旨在提升内容库的数据质量。通过引入自动化的清洗机制，剔除非中文和与AI领域无关的低质量数据（物理删除）。同时，提供批量重新生成摘要的能力，以确保所有内容的摘要质量一致。前端界面将升级，支持批量选择和操作，提升管理效率。

## User Stories

### Story 1: 内容智能清洗

As a 系统管理员, I want 自动剔除库中的劣质数据, so that 知识库只保留有价值的中文 AI 资讯

**Acceptance Criteria:**

- [ ] AC1: 识别非中文内容
  - **Given**: 内容库中存在纯英文或乱码内容
  - **When**: 触发清洗任务
  - **Then**: 扫描所有内容，计算汉字字符比例。若汉字比例低于 20%（可配置），则物理删除该记录及其关联数据。

- [ ] AC2: 识别非 AI 相关内容
  - **Given**: 内容库中存在与 AI 无关的新闻（如娱乐、体育）
  - **When**: 触发清洗任务
  - **Then**: 调用 AI 模型对内容标题和摘要进行判定。若判定为“无关”，则物理删除该记录。

- [ ] AC3: 物理删除执行
  - **Given**: 确定某条内容需要剔除
  - **When**: 执行删除操作
  - **Then**: 从数据库中永久删除该 `ContentItem`，并级联删除其关联的 `ContentNodeRelation`, `ValidationResult` 等数据。

### Story 2: 批量全量摘要生成

As a 系统管理员, I want 重新生成所有内容的摘要, so that 统一摘要风格并覆盖旧的低质量摘要

**Acceptance Criteria:**

- [ ] AC1: 批量生成触发
  - **Given**: 内容库中有 N 条数据（包含已有摘要和无摘要的）
  - **When**: 触发“重新生成所有摘要”任务
  - **Then**: 创建后台任务，遍历所有有效内容。

- [ ] AC2: 覆盖更新摘要
  - **Given**: 某条内容已有旧摘要
  - **When**: AI 生成新摘要成功
  - **Then**: 使用新摘要覆盖旧摘要，更新 `ai_processed=True`，并更新 `updated_at` 时间。

- [ ] AC3: 任务进度反馈
  - **Given**: 批量任务正在运行
  - **When**: 查询任务状态
  - **Then**: 返回当前进度（已处理数/总数）。

### Story 3: 内容库批量管理界面

As a 系统管理员, I want 在界面上批量选择内容, so that 我可以手动触发清洗或生成摘要

**Acceptance Criteria:**

- [ ] AC1: 多选列表支持
  - **Given**: 进入“内容库”页面
  - **Then**: 每一行内容前显示 Checkbox，表头显示“全选” Checkbox。

- [ ] AC2: 批量操作栏
  - **Given**: 选中了至少 1 条内容
  - **When**: 界面状态更新
  - **Then**: 顶部显示操作栏，包含按钮：“生成摘要”、“删除”。

- [ ] AC3: 触发批量摘要
  - **Given**: 选中了 N 条内容
  - **When**: 点击“生成摘要”
  - **Then**: 对选中的 N 条内容触发摘要生成任务，界面显示“正在处理...”提示。

- [ ] AC4: 触发批量删除
  - **Given**: 选中了 N 条内容
  - **When**: 点击“删除”并二次确认
  - **Then**: 物理删除选中的 N 条内容，列表自动刷新。

## Constraints

- **性能要求**: 批量 AI 任务不应阻塞主线程，需使用异步队列（当前架构支持 asyncio）。
- **成本控制**: 批量调用 AI 模型涉及大量 Token 消耗，需确保仅对有效内容调用（先清洗后摘要）。
- **数据安全**: 物理删除不可恢复，界面删除操作必须有二次确认弹窗。

## Out of Scope

- 数据恢复功能（Recycle Bin）
- 清洗规则的复杂可视化配置（目前通过代码常量或简单配置实现）

## Assumptions

以下假设已与用户确认：
- [x] 剔除操作为**物理删除**。
- [x] 使用 **AI 模型** 判断相关性。
- [x] 使用 **汉字比例** 判断语言。
- [x] 摘要生成为 **全量覆盖**。
