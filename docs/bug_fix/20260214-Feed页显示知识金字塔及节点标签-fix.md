# 20260214-Feed页显示知识金字塔及节点标签-fix.md 修复记录

## 问题描述
- **现象**：Feed 页的内容项（ContentItem）没有显示其所属的知识金字塔和具体的知识节点标签。
- **复现步骤**：打开 Feed 页面，查看内容列表。
- **影响范围**：Feed 页面内容展示。

## 设计锚定
- **所属规格**：FEAT_FEED_DISPLAY
- **原设计意图**：内容条目应与知识金字塔节点关联，并展示这种关联关系，以提供知识背景。
- **当前偏离**：前端 UI 未渲染这些关联信息，后端 API 未在内容列表中返回这些信息。

## 根因分析
- **直接原因**：后端 `ContentResponse` 模型中没有包含节点信息，前端 `FeedPage` 组件中没有渲染这些信息的代码。
- **根本原因**：内容项与节点的关系是多对多的，之前仅在 `ContentNodeRelation` 中维护，未在 `ContentItem` 模型中建立双向关系，导致查询不便且未暴露给前端。
- **相关代码**：
    - `backend/app/models/content.py`
    - `backend/app/schemas/content.py`
    - `backend/app/routers/contents.py`
    - `frontend/src/app/[locale]/(dashboard)/feed/page.tsx`

## 修复方案
- **修复思路**：
    1. 在后端 `ContentItem` 模型中添加与 `ContentNodeRelation` 的 `relationship`。
    2. 定义 `ContentNodeInfo` Pydantic schema 并将其添加到 `ContentResponse` 中。
    3. 在 `contents` 路由中使用 `selectinload` 预加载关联的节点和金字塔信息。
    4. 更新前端 TypeScript 类型定义。
    5. 在前端 `FeedPage` 组件的 footer 中添加渲染逻辑，使用 `Layers` 图标展示金字塔，并以标签形式展示节点。
- **改动文件**：
    - `backend/app/models/content.py`
    - `backend/app/schemas/content.py`
    - `backend/app/routers/contents.py`
    - `frontend/src/types/index.ts`
    - `frontend/src/app/[locale]/(dashboard)/feed/page.tsx`
