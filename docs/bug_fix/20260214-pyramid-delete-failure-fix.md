# 金字塔删除失败修复记录

## 问题描述
- **现象**：用户反馈“button 删除 金字塔失败”。这可能意味着点击无效，或者点击后提示删除失败。
- **复现步骤**：
  1. 进入金字塔列表页 `/pyramid`
  2. 点击删除按钮
- **影响范围**：金字塔列表页

## 设计锚定
- **所属规格**：`core-management-enhancement`
- **原设计意图**：用户可以通过卡片上的删除按钮删除金字塔。
- **当前偏离**：之前的 z-index 修复可能不彻底，或者错误处理不够友好。

## 根因分析
- **直接原因**：
  1. `z-10` 层级可能仍然不够高，或者在特定浏览器环境下被 `Link` 组件遮挡。
  2. 前端错误处理只提示“删除失败”，掩盖了真实的后端错误（如果有）。
- **根本原因**：卡片式布局中 `Link` 与操作按钮的层叠关系处理脆弱；错误反馈机制不完善。
- **相关代码**：`frontend/src/app/[locale]/(dashboard)/pyramid/page.tsx`

## 修复方案
- **修复思路**：
  1. 提高按钮容器的 `z-index` 到 20。
  2. 捕获并显示具体的后端错误信息。
  3. 添加调试日志以辅助排查。
- **改动文件**：`frontend/src/app/[locale]/(dashboard)/pyramid/page.tsx`
