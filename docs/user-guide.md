# AI Radar 用户指南

## 1. AI 服务配置

AI Radar 依赖 AI 模型提供智能分类、摘要生成和概念提取能力。在使用前，请确保正确配置 AI 服务。

### 1.1 访问配置页面
1. 点击左侧侧边栏底部的 **"设置" (Settings)** 图标。
2. 在顶部标签页中选择 **"AI 模型"**。

### 1.2 选择调度策略
系统支持三种调度策略：
- **本地优先 (Local First)**: 优先尝试本地模型（如 Ollama），失败后自动降级到云端服务。推荐开发和测试使用。
- **仅本地 (Local Only)**: 强制仅使用本地模型，确保数据隐私，不连接外网。
- **仅云端 (Cloud Only)**: 仅使用云端 API（如 SiliconFlow/OpenAI），适用于生产环境或无本地算力设备。

### 1.3 配置参数
- **API Key**: 云端服务必须。本地模型通常留空。
- **Base URL**: 
  - 云端默认: `https://api.siliconflow.cn/v1`
  - 本地默认: `http://localhost:11434/v1`
- **Model Name**: 模型名称（如 `Qwen/Qwen2.5-7B-Instruct` 或 `qwen2.5:7b`）。

### 1.4 测试连接
配置完成后，点击底部的 **"测试连接"** 按钮。系统将尝试发送一个简单的 "Hello" 请求，验证连通性和延迟。

## 2. 知识金字塔快照与回滚

为了防止误操作导致知识结构损坏，系统提供了快照保护机制。

### 2.1 创建快照
1. 进入任意 **知识金字塔详情页**。
2. 点击顶部的 **"历史快照"** 标签。
3. 点击 **"创建快照"** 按钮，输入备注（如"大规模重构前"），点击确认。

### 2.2 查看与预览
- 在快照列表中，点击 **"查看"** 图标，可以预览该快照时刻的金字塔节点结构。
- 预览界面展示了当时的节点层级和名称。

### 2.3 执行回滚
> **警告**: 回滚操作将覆盖当前的节点结构！建议在回滚前先创建一个当前状态的备份快照。

1. 在快照列表或预览对话框中，点击 **"回滚"** 按钮。
2. 系统会自动为当前状态创建一个"回滚前自动备份"。
3. 确认后，金字塔结构将恢复到选定快照的状态。

## 3. 内容自动分类与批量处理

系统能自动分析采集到的内容，提取标签、概念，并将其挂载到相关的金字塔节点上。

### 3.1 自动分类机制
- **实时处理**: 新采集的内容会自动进入处理队列。
- **元数据丰富**: AI 会生成摘要、提取 5 个关键概念和标签。
- **智能关联**: 系统计算内容向量与节点的相似度，自动建立关联。

### 3.2 手动触发批量处理
如果您导入了大量历史数据，或希望重新分析现有内容：
1. 进入 **"设置"** 页面。
2. 切换到 **"任务管理"** 标签页。
3. 在 "批量自动分类" 区域，点击 **"立即触发"**。
4. 任务将在后台运行，您可以在通知中心或日志中查看进度。

## 4. 信息源管理

### 4.1 添加信息源
1. 进入 **"信息源"** 页面。
2. 点击 **"添加信息源"**。
3. 支持 **RSS**、**网页** 等多种类型。
4. 输入 URL 后可点击 **"发现"** 自动识别名称。

### 4.2 生命周期管理
信息源状态会自动流转：
- **Active (活跃)**: 正常抓取更新。
- **Monitoring (监控)**: 连续多次抓取无更新或失败，降低抓取频率。
- **Adjusting (需调整)**: 长期失效，系统会生成"变更提案"，建议禁用或删除。
