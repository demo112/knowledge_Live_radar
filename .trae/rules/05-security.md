# 安全规范

| 规则 | 说明 |
|------|------|
| 禁止硬编码密钥 | API Key、数据库密码等使用环境变量 |
| 输入验证 | 所有用户输入必须通过 Pydantic 模型验证 |
| SQL注入防护 | 使用 SQLAlchemy 参数化查询，禁止拼接 SQL |
| XSS防护 | 前端输出转义，Next.js 默认防护 |
| CORS配置 | 明确配置允许的域名，禁止 `*` |
| 敏感操作日志 | 审批操作、配置变更必须记录 |
| API 密钥保护 | 硅基流动 API Key 仅在后端使用，禁止暴露给前端 |
| 速率限制 | 对 AI 服务调用和抓取接口实施速率限制 |
| robots.txt 遵守 | 爬虫必须遵守目标站点的 robots.txt |
| 域名白名单 | 信息源域名需在白名单中才可信任 |
