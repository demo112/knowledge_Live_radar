# AI Radar 项目概述

## 项目目标

AI Radar 是一个面向大模型应用领域的自进化知识聚合平台。系统具备感知（信息抓取）、认知（内容理解）、进化（结构优化）三大能力，通过 AI 驱动持续自我完善，人类作为最终决策者把控方向。

## 核心理念

1. **一切皆可进化** - 金字塔结构、信息源、抓取策略、系统自身都可进化
2. **AI 提议，人类决策** - AI 是顾问，人类是决策者，透明可追溯
3. **信息可靠性优先** - 只采信权威一手源，三层校验，宁缺毋滥

## 技术栈

| 模块 | 技术 | 版本/说明 |
|------|------|-----------|
| 前端 | Next.js + Tailwind CSS + ReactFlow + TypeScript | Next.js 16, React 19 |
| 后端 | Python FastAPI + SQLAlchemy (async) | Python 3.12, FastAPI 0.115+, SQLAlchemy 2.0 |
| 数据库 | PostgreSQL（生产）/ SQLite（开发） | aiosqlite / asyncpg |
| AI 服务 | 硅基流动 API | 大语言模型调用 |
| 部署 | Docker + Docker Compose | 后续容器化 |

## 当前实现状态（真实评估）

### ✅ 已基本完成（迭代 1 骨架）
- 数据模型：~35+ SQLAlchemy 模型已定义
- 基础 CRUD：金字塔、节点、信息源、内容的增删改查 API
- 前端页面骨架：金字塔可视化、信息源管理、审批中心、信息流等页面已搭建
- 数据库迁移：Alembic 配置就绪
- API 路由：30+ 路由已注册

### ⚠️ 存在但为空壳/桩代码（需要实质实现）
- **抓取引擎**：框架存在但部分抓取逻辑不完整
- **软性校验**：AI 质量评估桩代码
- **信息源生命周期**：状态流转逻辑不完整
- **信息源自动发现**：未实现
- **概念提取**：桩代码
- **重构建议器**：桩代码

### ❌ 尚未开始
- 用户多模态输入（PDF/Word/图片 OCR）
- 数据导入导出
- 性能优化（缓存、异步处理）
- 回滚机制
- AI 提示词管理界面
- 前端页面实质化（大部分页面为骨架）

## AI 行为规则

### 开发优先级判断

当前项目最大的问题是**大量桩代码需要实质化**。开发时应：

1. **优先补全核心链路**：抓取 → 校验 → 分类 → 入库 这条主线
2. **其次完善进化循环**：健康评估 → 问题检测 → 建议生成 → 审批执行
3. **最后处理辅助功能**：通知、搜索高级功能、性能优化
