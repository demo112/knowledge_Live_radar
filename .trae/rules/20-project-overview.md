# AI Radar 项目概述

## 项目目标

AI Radar 是一个面向大模型应用领域的自进化知识聚合平台。系统具备感知（信息抓取）、认知（内容理解）、进化（结构优化）三大能力，通过 AI 驱动持续自我完善，人类作为最终决策者把控方向。

## 核心理念

1. **一切皆可进化** - 金字塔结构、信息源、抓取策略、系统自身都可进化
2. **AI 提议，人类决策** - AI 是顾问，人类是决策者，透明可追溯
3. **信息可靠性优先** - 只采信权威一手源，三层校验，宁缺毋滥

## 技术栈

| 模块 | 技术 |
|------|------|
| 前端 | Next.js + Tailwind CSS + ReactFlow + TypeScript |
| 后端 | Python FastAPI + SQLAlchemy |
| 数据库 | PostgreSQL（生产）/ SQLite（开发） |
| AI 服务 | 硅基流动 API |
| 部署 | Docker + Docker Compose |

## 核心模块

| 模块 | 说明 |
|------|------|
| 知识金字塔 | 层级化知识组织结构，支持 CRUD、模板、可视化 |
| 信息源管理 | RSS/API/网页爬取，生命周期管理，健康监测 |
| 抓取引擎 | 定时抓取、去重、并发控制、robots.txt 遵守 |
| 三层校验 | 硬性规则校验 + AI 软性校验 + 多源交叉验证 |
| 审批系统 | AI 生成变更提案，人类审批决策 |
| 进化引擎 | 健康检测、重构建议、策略自适应 |
| 热点追踪 | 热点生命周期管理、概念漂移检测 |

## 迭代计划

| 迭代 | 内容 |
|------|------|
| 迭代 1 | 骨架搭建（基础架构、核心数据模型、基本 UI） |
| 迭代 2 | 信息抓取（动态信息源、抓取引擎、校验机制） |
| 迭代 3 | 用户输入与金字塔进化（多模态输入、概念提取、审批系统） |
| 迭代 4 | 自我进化（健康检测、重构建议、策略自适应） |
| 迭代 5 | 完善与 Docker 化（性能优化、监控完善、容器部署） |
