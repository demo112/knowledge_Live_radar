# 语言规范

## 核心原则

1. **全站中文**：所有用户可见内容必须使用中文。
2. **拒绝英文**：除非是专有名词、代码变量名或无法翻译的技术术语，否则禁止出现英文。
3. **一致性**：使用的中文术语必须保持全站一致。

## 适用范围

### 1. 用户界面 (UI)
- 页面标题、按钮文字、标签、菜单项
- 提示信息 (Toast, Tooltip)
- 表单占位符 (Placeholder)
- 空状态描述 (Empty State)
- 模态框标题和内容

### 2. 反馈与报错
- 后端 API 返回的错误信息 (`message` 字段)
- 前端捕获异常后的展示信息
- 表单验证错误提示

### 3. 日志与文档
- 业务日志中的描述性文字推荐使用中文（方便排查）
- 所有项目文档 (Markdown) 必须使用中文
- Git Commit Message 必须使用中文（遵循 `07-git-basic.md`）

### 4. 数据内容
- 预设数据（如初始分类、示例数据）必须是中文
- 自动生成的内容（如 AI 总结、报告）必须要求 AI 输出中文

## 实施指南

- **后端**：在 `raise HTTPException` 或返回 `ErrorResponse` 时，确保 `detail` 或 `message` 是中文。
- **前端**：检查所有硬编码的文本，确保为中文。
- **AI Prompt**：在调用 AI 服务的 Prompt 中，明确指定 "Please answer in Chinese" 或 "请使用中文回复"。
