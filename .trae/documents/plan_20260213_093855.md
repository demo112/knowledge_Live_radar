# 系统修复计划：初始化演示数据

经过系统化排查，我发现服务（前后端）均运行正常，数据库连接也正常。用户感觉“不能用”的根本原因在于**系统的“空状态”体验存在断层**：

1.  **金字塔列表为空**：初次进入无内容。
2.  **创建后无法操作**：新建金字塔为空白状态，而前端可视化界面目前依赖“右键点击已有节点”来进行操作，导致**没有节点就无法创建节点**的死循环。

为了立即解决“不能用”的问题，我将通过脚本注入一套完整的演示数据，让您可以直接体验系统的核心功能。

## 1. 创建数据初始化脚本
将在 `backend/scripts/seed_data.py` 创建脚本，包含：
- **演示金字塔**：创建名为 "AI 知识图谱" 的金字塔。
- **层级结构**：
    - **L0**: 人工智能 (Root)
    - **L1**: 机器学习、深度学习、自然语言处理
    - **L2**: 大语言模型 (LLM)、Transformer、计算机视觉、强化学习
    - **L3**: GPT-4, LLaMA, BERT, Stable Diffusion

## 2. 执行初始化
- 运行脚本注入数据到 SQLite 数据库。
- 这将立即填充 Dashboard 和金字塔视图。

## 3. 验证修复
- 通过 API 确认数据已写入。
- 完成后，您只需刷新前端页面，即可看到可交互的金字塔结构，并进行后续的拆分、合并等操作。

## 后续建议（非本次）
- 前端需要增加“空状态”引导：当金字塔为空时，显示显著的“添加根节点”按钮。
